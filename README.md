# ARK POS

ARK POS is a modern point-of-sale interface designed for small-business retail workflows, with a fast product-first experience and a clean operational dashboard.

## Stack
- React
- Vite
- JavaScript
- ESLint

## Focus
- Product and cart workflows
- Checkout-oriented interface
- Responsive POS experience
- Clear operational UI suitable for small retail businesses

## Local development
npm install
npm run dev

Production build: npm run build, then npm run preview.

Built as an ARK II portfolio/product project.
